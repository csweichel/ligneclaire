# Hilbert Loops Gradient

`hilbert-loops-gradient` ports the nested Hilbert loop study from `go-pen`.

## Parameters

- `loops`: number of nested Hilbert loops
- `order`: Hilbert curve order
- `thickness`: maximum added stroke lanes near the center
- `base`: minimum added stroke lanes at the edges

## Validation Cases

- `default`: the default multi-loop A3 poster composition
