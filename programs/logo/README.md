# Logo Field

`logo` ports the original `go-pen` logo sketch by clipping a compact flow field into the logo silhouette.

## Parameters

- `seed`: deterministic field seed
- `paths`: number of traced strokes
- `scale`: logo mark scale
- `segmentLength`: travel distance per field step
- `steps`: number of steps per traced path

## Validation Cases

- `default`: the standard clipped mark
