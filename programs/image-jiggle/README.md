# Image Jiggle

`image-jiggle` ports the `go-pen` image-driven sine-line technique.

## Parameters

- `lineCount`: number of horizontal jiggle lines
- `stepsPerLine`: sample count per line
- `maxAmplitude`: maximum vertical jiggle amplitude
- `maxFrequency`: maximum local oscillation frequency

## Validation Cases

- `default`: the reference sampled portrait render
