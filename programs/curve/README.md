# Continuous And Discrete Curve

`curve` ports the original `go-pen` curve demo by overlaying a sampled sine wave with a fitted discrete dataset.

## Parameters

- `cycles`: number of sine cycles across the box
- `samples`: segment count for the continuous curve
- `amplitude`: vertical occupancy of the continuous curve within its box
- `showDiscrete`: toggles the discrete reference polygon

## Validation Cases

- `default`: the standard sine-plus-polygon overlay
