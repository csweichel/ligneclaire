# Isometric Ribbons

`isometric-ribbons` builds a dense field of stepped isometric ribbon curves inspired by woven blue line studies on a staggered lattice.

## Parameters

- `seed`: deterministic field seed
- `cellSize`: motif scale in millimeters
- `lanes`: number of parallel offsets per motif
- `laneGap`: spacing between adjacent ribbon lanes
- `fieldScale`: size of the regional orientation field
- `disorder`: amount of local variation mixed into the field
- `dualHanded`: mixes mirrored staircase motifs into the field

## Validation Cases

- `default`: balanced square crop with dense dual-tone ribbons
