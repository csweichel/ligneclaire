# Image Circles

`image-circles` ports the `go-pen` raster-to-plot technique that replaces grayscale samples with hatched circles.

## Parameters

- `columns`: sampling columns
- `rows`: sampling rows
- `maxRadius`: maximum circle radius
- `minHatchSpacing`: densest hatch spacing
- `maxHatchSpacing`: lightest hatch spacing

## Validation Cases

- `default`: the reference sampled portrait render
